### 用途

本 Skill 旨在为影视、广告及 AI 视频前期创作提供专业的剧本全案处理，包括深度解析、逻辑诊断、授权改稿及版本锁定，确保叙事连续性与制作可行性。

### 适用输入

- 电影、剧集、短片或广告的完整剧本或选段。
- 格式支持：DOCX、PDF、FDX、Markdown 或直接粘贴的纯文本。

### 操作步骤

1. **阶段 1：剧本解析**
   - 提取剧本事实：动作、对白节拍、环境要素。
   - 导演判断：叙事功能、情绪流向、张力变化。
   - 连续性追踪：人物、地点、道具的跨场次状态记录。
2. **阶段 2：导演诊断**
   - 核心因果链与信息释放策略分析。
   - 识别客观矛盾、连续性风险与艺术机会。
   - 估算时长节奏，评估制作风险。
3. **阶段 3：授权改稿**
   - 根据用户授权的“白名单”内容进行定向修改。
   - 提供修订前后的对比记录与连带影响检查。
   - 输出完整的新版剧本正文。
4. **锁定摘要**
   - 在用户确认后生成最终锁定版本摘要，记录已解决的问题与保留的例外。

### 输出要求

- 使用简洁的 Markdown 标题与列表，严禁堆叠表格或输出 JSON/YAML 原始数据。
- 每个判断必须有据可查，区分“剧本事实”与“导演判断”。
- 场次使用稳定 ID（如 SC001），问题使用风险编号（如 CR01）。
- 篇幅较长时按阶段或场次分段输出，并标注序号。

### 注意事项

- 严禁在未经授权的情况下修改剧本事实或补写未决项。
- 不涉及具体的镜头设计、运镜或视觉风格描述。
- 只有在全片范围明确且矛盾解决后，方可生成“锁定摘要”。
