# 光线场景预设

按用户场景读取相关类别。先替换人物方位、场景光源和受光区域，再把模块放入视频提示词。不要把多套预设原样叠加。

## 目录

- 自然与日间光
- 夜景与实景光源
- 舞台与棚拍光
- 反射与风格化光

## 自然与日间光

### 窗边柔光

适合独白、回忆、室内生活戏和温柔人物近景。

```text
【光线布置】以窗边自然柔光作为主光，光源从人物侧前方斜向进入，柔和照亮半边脸、眉眼、鼻梁、嘴唇、手部和衣领。另一侧脸缓慢进入自然阴影，保留皮肤纹理和五官结构。正面只有极弱漫反射补光，眼睛中保留温润眼神光。背景轻微虚化，窗外高光不过曝。
```

### 顶部天光

适合白天室外、天井、车站和自然生活感画面。

```text
【光线布置】以顶部或斜上方自然天光作为主光，柔和覆盖头顶、肩膀、发丝和上半身。脸部曝光自然，眼窝、鼻梁下方和下巴保留轻微阴影。正面加入少量地面反射光，避免眼睛过暗。背景明亮且保留层次，不出现整张脸平均发白。
```

### 阴天漫射光

适合雨后、写实短剧、清冷情绪和低反差外景。

```text
【光线布置】厚云层形成大面积冷灰色漫射环境光，没有清晰硬阴影。人物、服装和背景被柔和覆盖，整体光比较低，五官与衣料纹理仍然清楚。人物正面不增加强补光，只保留自然眼神光。背景饱和度略低，避免灰雾覆盖整幅画面。
```

### 黄金时刻逆光

适合相遇、回眸、离别、怀旧和人物情绪高点。

```text
【光线布置】低角度暖金色阳光从人物侧后方照来，打亮发丝、肩膀、侧脸轮廓和衣服边缘。正面使用同方向环境反射形成柔和暖色补光，保留面部结构。空气中只有轻微雾感，边缘光明亮但不过曝，背景呈暖色散景。
```

### 清晨薄雾光

适合清晨外景、安静开场和带空间纵深的场面。

```text
【光线布置】清晨低角度柔光从侧后方穿过薄雾，轻轻照亮发丝、肩部、脸部侧缘和衣料纹理。正面以极弱环境反射保留面部层次。雾气在光路中形成柔和体积光，远景逐渐淡化，主体区域保持清楚，不被白雾遮盖。
```

## 夜景与实景光源

### 月光冷光

适合独处、悬疑、古风夜戏和冷感人物镜头。

```text
【光线布置】蓝白色月光从人物侧上方或侧后方照来，打亮一侧脸、发丝、肩膀和衣服边缘。正面只保留极弱冷灰色环境补光，暗区仍有眼眶和下颌结构。背景整体压暗，远处仅有微弱环境亮度。月光方向与阴影方向保持一致。
```

### 烛光暖光

适合夜谈、书信、密会和私密室内戏。

```text
【光线布置】人物侧前方近距离烛火发出暖黄色柔光，照亮靠近烛火的一侧面颊、下巴、嘴唇、鼻梁下缘、手指和衣服前襟。光照范围有限，离开烛火后快速衰减。亮度只有轻微自然跳动，脸部结构保持稳定，背景较暗并有少量虚化烛火。
```

### 灯笼环境光

适合灯会、夜市、古风相遇和节庆场景。

```text
【光线布置】人物手边和环境中的灯笼提供暖色实景光，最近的灯笼照亮侧脸、手部、衣袖和邻近地面，远处灯笼只形成柔和散景。正面有微弱环境回填，人物边缘带一点暖色轮廓。各灯笼亮度按距离衰减，避免整条街平均染成橙色。
```

### 火光跳动光

适合战前、逃亡、野外对峙和危险场面。

```text
【光线布置】侧前方或下方的篝火提供橙红色近身主光，照亮一侧脸、手部、衣服褶皱和附近地面。火光以不规则的小幅度变化轻微跳动，色温与亮度缓慢波动，暗区保留结构。眼睛中有细小火光反射，背景深色并有少量烟雾。避免高频闪烁和全脸变形。
```

### 霓虹侧光

适合都市夜景、赛博空间、雨夜和孤独人物。

```text
【光线布置】侧方城市招牌提供霓虹色主光，一侧冷色光照亮脸部与头发边缘，邻近暖色招牌只在另一侧留下局部反射。正面加入极弱中性补光，保留皮肤本色与五官结构。湿地反射霓虹颜色，背景灯牌虚化。避免多种颜色平均涂满皮肤。
```

### 雨夜路灯光

适合等待、分离、重逢和情绪爆发前的镜头。

```text
【光线布置】侧上方或背后的路灯穿过雨丝，照亮头发、肩部、伞面和衣服边缘。人物正面由湿地与周围建筑提供微弱环境反射，脸部暗区不死黑。雨水只在经过光路时变亮，湿地形成方向一致的反射。背景压暗并保留少量灯光散景。
```

### 车灯逆光

适合追车、对峙、逃亡和夜间动作场景。

```text
【光线布置】车辆前灯从人物背后低位射来，形成强烈侧逆光，打亮头发、肩部、腿部边缘并在地面投下长阴影。正面只有极弱环境补光，保留少量脸部结构。空气中的雨、雾或尘埃让车灯光路可见。两束车灯的位置和阴影方向保持对应，避免无来源正面亮光。
```

## 舞台与棚拍光

### 舞台追光

适合登场、表演、觉醒和仪式场面。

```text
【光线布置】舞台追光从正上方或斜上方集中照下，覆盖人物脸部、肩膀、上半身和脚下区域。背景大面积压暗，主体从黑场中突出。正面加入少量柔和补光，避免眼窝完全变黑。薄雾只在光柱内部可见，追光边缘清楚且不过度锐利。
```

### 聚光灯硬光

适合审问、真相揭开、孤立和心理压力镜头。

```text
【光线布置】窄束聚光灯硬光从人物侧上方照下，集中打亮半边脸、肩膀和关键道具，照明区域边缘清楚，背景迅速进入暗部。正面只加入极弱补光，保留暗区五官结构。阴影方向明确，高光不能吃掉皮肤纹理。
```

### 轮廓剪影光

适合人物登场、背影、悬念和强轮廓画面。

```text
【光线布置】强逆光位于人物正后方，正面大部分保持暗部，只在朝向光源的头发、肩膀、侧脸和衣服边缘形成清晰亮边。正面补光极弱，仅保留少量五官暗部。背景光源明亮但不过曝，轮廓光不能均匀环绕全身。
```

### 高调棚拍光

适合美妆、服装展示、白底人像和干净商业画面。

```text
【光线布置】大面积正前方偏上柔光作为主光，均匀照亮脸部、皮肤和服装，两侧使用宽柔补光降低阴影反差。眼睛中保留明亮自然的眼神光。浅色背景独立照明且不过曝，人物边缘仍与背景分开。皮肤保持纹理，避免塑料感和纯白鼻梁高光。
```

### 低调暗场光

适合悬疑、复仇、秘密对话和人物心理戏。

```text
【光线布置】窄范围侧前方主光只照亮半边脸、眼神、手部或关键道具，其余区域大面积进入暗部。正面只保留极弱补光，暗区仍能辨认眼眶和下颌。背景保持深色并弱化细节。黑位克制，不用纯黑吞掉轮廓。
```

## 反射与风格化光

### 反射补光

适合写实外景、生活短剧和自然人像。

```text
【光线布置】侧方自然光负责人物一侧脸和身体边缘，地面、墙面、水面或白色反光板从正面偏下方柔和回填暗部。反射光强度明显低于主光，色彩受到反射表面轻微影响。面部阴影变柔和，仍保留立体结构与自然眼神光。
```

### 水面反射光

适合水边、雨后、庭院和奇幻氛围镜头。

```text
【光线布置】水面把环境光反射到人物下方和侧下方，在脸部、脖颈、衣服与邻近墙面形成柔和波动亮纹。反射变化缓慢并服从水面运动，主光方向保持稳定。亮纹只出现在能接到反射的表面，避免整张脸持续闪烁。
```

### 彩色分离光

适合人物对立、情绪冲突、品牌大片和强风格画面。

```text
【光线布置】一侧暖色光照亮人物脸部、肩膀和衣服边缘，另一侧冷色光勾勒头发、侧脸与背景轮廓。正面使用微弱中性补光保护皮肤本色和五官结构。冷暖区域各有明确来源与边界，不在脸部中央混成脏色。背景对应两侧光源形成冷暖分区。
```

## 组合规则

- 从一个环境或主光开始，再按需要加补光和分离光。
- 近身实景光优先影响最近表面，环境光继续控制远处空间。
- 同时使用冷暖光时，为每种颜色指定不同方向和受光区域。
- 体积光依赖雾、烟、雨、雪或尘埃，空气干净时不要凭空加入光柱。
- 火光允许不规则微动，晶体、路灯和棚灯默认稳定。
