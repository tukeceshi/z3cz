## 从抽象词改成可见结果

弱写法只表达愿望。

```text
电影感打光，冷暖对比，神秘而高级，画面真实有质感。
```

改写时指定光源与结果。

```text
冷灰色窗光从人物左后方进入，照亮左侧发丝、耳廓和肩膀边缘，背景保持偏暗。人物右手中的小型烛灯发出暖光，只照亮手指、下巴和右侧脸颊下部。正面加入极弱柔和补光，保留面部暗区的五官结构。冷窗光负责人物轮廓，暖烛光负责脸部局部。高光不过曝，暗区不能完全死黑。
```

用演员和灯能否在现场实现这段关系作为检查标准。

## 单镜头光线模板

```text
【光影意图】

观众首先看见主体的某个区域，背景与次要物件保持较弱。

【环境光】

场景由某种环境光提供基础曝光。写明时间、天气、方向、颜色和硬度，以及它如何影响背景。

【主光】

主光来自某个可解释光源，位于主体某个方向。它照亮具体的脸部、身体、产品或道具表面，形成明确亮暗关系。

【补光与分离】

正面或环境反射只回填必要暗部。需要时用侧后方轮廓光分离主体。写明眼神光是否保留。

【曝光与限制】

指定暗区保留什么，高光保护什么。限制无来源光、过曝、整圈描边、过大光晕、杂乱投影和不合理可见光束。
```

## 多镜头连续性模板

先写全局不变量，再写每个镜头的受光变化。

```text
【全局光线状态】

环境主光的方向、色温和相对亮度在所有镜头中保持一致。实景灯或发光道具的颜色、强度、作用半径与闪烁规律保持一致。白平衡和曝光基准不自动改变。

【镜头一】

写明光源在画内或画外的位置，当前照亮哪些表面，哪些区域留暗。

【镜头二】

写明机位改变后同一光源的屏幕方向，以及新的最近受光表面。保留与镜头一相同的色温和强度。

【镜头三】

人物或道具移动时，描述亮区怎样跟随。光源被遮挡时，让被遮挡区域合理变暗。

【连续性限制】

禁止光源方向突变、亮度跳变、白平衡漂移、作用范围扩大、阴影反转和无来源新增光。
```

## 移动道具光模板

```text
【近身道具光】

人物手中的发光道具位于某个位置，发出稳定或按剧情变化的某色光。光线只影响道具周围明确距离，照亮最近的手指、皮肤和衣料，超过范围迅速衰减。

道具从位置一移动到位置二时，亮区跟随道具从原受光表面转移到新受光表面。被手掌或身体遮挡时，对应光线减弱。远处背景继续由环境光控制。

指定道具亮度是否恒定，是否允许闪烁、脉冲、呼吸变化或渐变。未明确允许的变化全部禁止。
```

## 诊断与修订模板

诊断已有提示词时按以下顺序输出。

1. 列出最多五个影响最大的光线问题。
2. 解释问题会在画面中产生的可见后果。
3. 给出保持剧情和镜头不变的修订版光线模块。
4. 多镜头时单列连续性锁定。

优先检查这些问题。

- 光源没有身份或位置。
- 多束光都要求成为主光。
- 冷暖色落在相同皮肤区域并互相污染。
- 小道具照亮整个场景。
- 轮廓光均匀环绕人物。
- 暗部同时被要求深黑和保留全部细节。
- 画面无雾却要求清晰体积光束。
- 发光物被要求恒定，又被要求脉冲或爆发。
- 镜头切换后光源换边，阴影方向却没有变化。
- 风格词、画质词和摄影师姓名挤掉了可执行光线关系。

## 十五秒完整案例

```text
冷灰色雪原上的奇幻人物短片，时长十五秒，四个镜头。阴天天光柔和扩散，没有直射太阳。冷色环境光始终负责人物整体轮廓、雪地和远处空间。

人物右手捏着一枚五厘米高的透明晶体。晶体内部持续发出稳定暖白光，亮度从开场到结尾不变。暖光只影响晶体周围五到十厘米，照亮最近的皮肤、指尖和衣料边缘，超过范围迅速衰减。无闪烁、无脉冲、无大面积光晕、无镜头光斑。

镜头一  零到三秒

脸部近景，摄影机位于人物右前方轻微低机位。人物低头看向画外右下方的晶体。晶体暖光从右下方照亮下唇、下巴、鼻子下缘和右侧脸颊下部。额头、头发上方和左侧脸部仍处于冷灰色天光中。暗区保留眉眼与颧骨结构。

镜头二  三到七秒

硬切到右肩后方的紧凑越肩镜头。人物右肩和头发位于前景虚焦，右手与晶体处于画面中央。晶体暖光只照亮拇指、食指、手背局部和金属托爪内侧。远处雪地保持冷灰色，不能被晶体照亮。

镜头三  七到十秒

硬切回镜头一的相同机位和景别。晶体仍位于画外右下方，暖光以相同角度照亮脸部下缘，亮度和范围与镜头一一致。人物表情改变，光源状态不变。

镜头四  十到十五秒

胸口中景，摄影机仍在人物右前方。右手把晶体慢慢移向胸口，暖光跟随晶体，先照亮指尖与手背，再照亮胸口接触点。晶体进入身体以后，手上的外部暖光消失，相同暖白光转移到胸口皮下，形成范围克制的皮下亮区。

四个镜头保持相同的环境光方向、雪地亮度和晶体色温。禁止突然改变光源方向，禁止整个身体一起发亮，禁止增加横向光带、星芒和过曝白斑。
```

## 常见冲突

### 平均光与大光比同时出现

选择一个明确目标。想要低调情绪时压低补光，只保留必要结构。想要商业清晰度时降低光比，不要继续要求大面积深黑。

### 柔光与锐利投影同时出现

把它们分给不同光源。大面积柔光负责人物，窄束硬光负责背景投影。不要让同一束光同时柔和包裹主体并产生刀切般阴影。

### 暖光与冷光同时覆盖整张脸

为两种颜色分配不同方向、区域和强度。保留中性或接近肤色的一侧，避免皮肤变成均匀双色塑料表面。

### 月光与室内灯方向互相冲突

根据窗户和灯具位置重建空间。窗外月光只能从开口进入，室内灯只影响无遮挡的邻近表面。

### 恒定光与剧情闪烁冲突

明确时间段。写清何时稳定、何时开始变化、变化幅度与结束状态。不要在全局锁定恒定后又让同一光源持续脉冲。

### 光束与干净空气冲突

删除光束，或者增加符合场景的薄雾、烟、雨、雪或尘埃，并控制浓度，避免主体被雾覆盖。
