# 第 2 步:字幕擦除后端链路(按当前 UI 重新整理)

## 现状确认(已完成,无需改动)
- 前端提交:`submitVideoSubtitleErase` → `POST /mediakit/subtitle-erase/submit`,body 含 mode(standard/refined)+ 精细化参数(eraseMode subtitle|text / modelVersion v4|v5 默认v5 / outputEncodeMode quality|size / eraseRatioLocation 0–20 个归一化矩形)
- 生成流程:面板建兄弟节点 shell → 提交(nodeId=兄弟节点)→ 写 generating/jobId metadata → 兄弟节点经通用 auto-resume 轮询收结果(与裁剪 runCloudTrim 同构)
- types 中请求/响应类型、jobKind="video_subtitle_erase"、能力配置(standard/refined 开关+API Key)均已就绪

## 改动清单

### 1. `apps/api/src/integrations/volcengine/mediakit-client.ts`
- 端点映射:`standard → /api/v1/tools/erase-video-subtitle`,`refined → /api/v1/tools/erase-video-subtitle-pro`
- 新增 `submitMediaKitSubtitleEraseTask({ apiKey, videoUrl, mode, eraseMode?, modelVersion?, outputEncodeMode?, eraseRatioLocation?, clientToken?, upstreamLog? })`:
  - standard body:`{ video_url, client_token? }`
  - refined body:追加 `mode: "Subtitle"|"Text"`(subtitle→Subtitle、text→Text)、`model_version: "v4"|"v5"`、`output_encode_mode: "Quality"|"Size"`(quality→Quality、size→Size)、`erase_ratio_location: [{ top_left_x, top_left_y, bottom_right_x, bottom_right_y }]`(仅传有值字段)
  - standard 模式忽略精细化字段
- 轮询复用现有 `pollMediaKitTask`(GET /api/v1/tasks/{taskId},响应同为 result.video_url)

### 2. 新增 `apps/api/src/services/video-subtitle-erase-service.ts`(逐段仿 video-enhance-service.ts)
- `submitVideoSubtitleEraseTask`:接口行校验(用 `listEnabledVolcanoMediaKitSubtitleEraseModes` 断言 mode 开启)→ 解析 API Key → resolveResourceRefs 源视频 → 占位资源注册 → 创建 generationJob(jobKind=video_subtitle_erase, status=generating)→ AI invocation(promptExcerpt 含 mode/参数摘要, source="ai-video-subtitle-erase-submit")→ 上游提交,失败回滚(job/资源/invocation 标记失败)→ 写 upstreamTaskId
- `pollVideoSubtitleEraseGenerationJob`:仿 enhance 轮询(节流 nextUpstreamPollAt;失败/取消/成功分支;成功→buildVideoPendingMedia→ready_to_persist)

### 3. `apps/api/src/services/generation-job-service.ts`
- `pollVideoGenerationJob`(L504-518)增加 `video_subtitle_erase` jobKind 分支
- 取消/兜底持久化/刷新均为按 modality 的通用逻辑,确认无需改动即可

### 4. `apps/api/src/routes/platform-ai.ts`
- `submitSubtitleEraseSchema`:aiInterfaceId、sourceVideoResourceId、mode(枚举)、refined 可选字段(eraseMode/modelVersion/outputEncodeMode 枚举;eraseRatioLocation 数组 ≤20 且坐标 0–1)、workflowId/nodeId/clientRequestId 可选
- `POST /mediakit/subtitle-erase/submit`(仿 enhance 路由):clientRequestId 幂等(复用 buildVideoSubmitResponseFromJob)→ 节点活跃任务 409 → cloud storage gate → 调 service → `persistGeneratingNodeContentToWorkflow`(params.videoSubtitleErase)→ 返回 taskId/jobId/resourceIds/workflowNodeContent

- persist-worker / refreshGenerationJob / maybeRunServerPersistFallback 的通用性
